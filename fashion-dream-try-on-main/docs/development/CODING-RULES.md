# Coding Rules

## Nguyên tắc thay đổi

1. Xác định nguyên nhân trước khi sửa.
2. Chỉ sửa phần cần thiết.
3. Giữ nguyên tính năng đang hoạt động.
4. Không tạo component/file trùng chức năng.
5. Với thay đổi lớn, chia thành các bước nhỏ.
6. Không reset, overwrite hoặc xóa code cũ khi chưa xác định rõ phạm vi.

## Quy trình

Problem → Diagnose → Identify Layer → Identify File → Minimal Change → Test → Commit → Deploy → Verify
