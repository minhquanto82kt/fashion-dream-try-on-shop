# WEARO Documentation

Tài liệu kỹ thuật và vận hành của WEARO.

## Cấu trúc

- `product/` — định hướng sản phẩm và hệ thống thương hiệu.
- `architecture/` — kiến trúc ứng dụng và dữ liệu.
- `development/` — quy tắc phát triển, CRUD và API.
- `admin/` — tài liệu vận hành khu vực quản trị.
- `ai/` — tài liệu tính năng AI Try-On.
- `operations/` — tài liệu regression, deployment và vận hành.

`docs/` chỉ chứa tài liệu đang có giá trị đối với codebase hiện tại; không dùng để lưu lịch sử trao đổi hoặc prompt tạm thời.
